# Heart Disease Prediction System
A comprehensive data science project that combines Exploratory Data Analysis (EDA), Machine Learning model training, and an interactive Streamlit web application for heart disease prediction.

# Key Features

Predicts heart disease risk using machine learning models.

Clean and preprocessed medical dataset for accurate results.

Exploratory Data Analysis (EDA) with charts and correlations.

Multiple ML algorithms: Logistic Regression, Random Forest, SVM, KNN.

Compares model performance and selects best one.

User-friendly Streamlit web interface for real-time predictions.

# Technical Highlights

Feature scaling, encoding, and model evaluation pipeline.

Train/Test split with accuracy, precision, recall & F1-score metrics.

Visualizations to understand patterns and relationships.

Saved trained model for instant prediction in the app.

Modular project structure with clean code organization.

# Usage

Enter patient parameters in the web app.

Click predict to get heart disease risk.

Simple UI suitable for medical analysis demos.
